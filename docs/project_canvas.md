# Project Canvas  : 발달장애 근로자 직장 의사소통 훈련 서비스

## 1. 프로젝트 문제

발달장애 근로자는 직장 내 의사소통 상황에서 적절한 언어 표현을 선택하는 데 어려움을 겪는다. 기존 훈련은 오프라인 매뉴얼 중심이라 반복 실습과 즉각적 피드백이 어렵다.

## 2. 사용자 / 시나리오

### 사용자

- 주 사용자: 발달장애 근로자
- 보조 사용자: 직무지도교사, 관리자

### 상황 카테고리

사용자는 다음 4개 상황 카테고리 중 하나를 선택한다.

- 근로지원 상황대응
- 관리자 응대
- 안전 위험상황
- 고객서비스·직장매너

### 시나리오

근무 전 또는 여유 시간에 사용자는 상황 카테고리를 선택하고, 예상 답변을 음성으로 말하며 반복 연습한다.

AI는 사용자의 발화를 분석해 표현 적절성 피드백과 대안 표현을 즉시 제공한다. 이를 통해 사용자가 실제 업무 상황에 앞서 적절한 언어 표현을 미리 익힐 수 있도록 돕는다.

## 3. 논문에서 가져올 아이디어

OLMo 논문에서 가져올 핵심 아이디어는 공개 가중치와 체크포인트를 활용해 모델의 학습 단계별 변화를 직접 비교할 수 있다는 점이다.

본 프로젝트에서는 이 아이디어를 직장 의사소통 피드백 모델 개발에 적용한다. Base, SFT, Instruct 모델의 동일 입력 응답을 비교하여 어떤 단계의 모델이 더 적절하고 쉬운 피드백을 제공하는지 확인한다.

이후 확보 가능한 직장 의사소통 데이터로 도메인 튜닝을 시도할 경우, 튜닝 전후 응답 변화를 비교해 도메인 데이터가 피드백 품질에 미치는 영향을 추적한다.

## 4. 데이터 / 입력

장애인고용공단(KEAD) 직장 지원 매뉴얼, 공공기관 안전 매뉴얼, 자체 제작 시나리오 80개 → 총 500개 태스크로 구성

- 근로지원 상황대응 120
- 쉬운 설명 변환 90
- 관리자 응대 80
- 직무지도 체크리스트 80
- 안전 위험상황 70
- 노동권·상식 40
- 고객서비스·매너 20

## 5. 모델 / Agent / MCP 구성

OLMo2-1B 베이스 → LoRA(파라미터 0.07%) 경량 파인튜닝 → SFT 후 DPO로 선호 응답 정렬. Agent/MCP 없이 단일 모델 추론 파이프라인(입력 상황 텍스트 → 피드백+선택지 3가지 생성)으로 MVP 구성.

## 6. MVP 기능

사용자가 직장 상황을 텍스트로 입력, 모델이 (1) 언어적 피드백 (2) 상황에 맞는 표현 선택지 3가지를 생성하여 제공. 입력 예시 20~30개, 태스크 카테고리 7개로 최소 실행 가능 범위 확보.

## 7. 평가 지표

최소 평가 지표는 응답 적절성, 친절성, 구체성, 안전성이다. 
추가로 Base→SFT→Instruct→Domain-tuned 모델 간 응답 변화, 도메인 상황 반영 여부, 부적절한 조언 비율, 피드백 일관성, 추론 시간, 메모리 사용량을 기록한다. 

## 8. 예상 위험과 방어

- 데이터 500개 소량 → 편향/과적합 가능 → 데이터 확장 계획 필요
- 한국어 토크나이저 비효율 → 응답 품질 저하 가능성
- 안전 관련 오답 시 실제 위험 노출 가능 → 안전 카테고리는 사람 검수 필수
- 개인정보(장애인 관련 민감정보) → 학습·로그 데이터 익명화, 접근 권한 제한

## 9. 발표 후 1주 내 실행 계획

① 도메인 데이터 500→5000개 확장  
② 안전 카테고리 응답 전문가 검수 프로세스 구축  
③ 평가셋(20개) 기반 LoRA 재학습·비교  
④ 한국어 토크나이저 교체 실험 착수
